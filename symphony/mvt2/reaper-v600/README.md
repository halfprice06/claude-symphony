# Movement II mockup in REAPER, series 2 (EastWest Hollywood Orchestra Opus Edition)

Mockup of `symphony/mvt2/v600` (Symphony No. 1, II. Adagio, A flat major), built by script through the REAPER file bridge and improved by the actor-critic loop in `loop/`. This folder is local and kept out of git (`.git/info/exclude`). Series 1 (`symphony/mvt2/reaper/`, score v77, cycles c00-c26) is read only; its cycle folders are linked into `cycles/`. The method and tools come from `mockup-kit/` (read its README and LEARNINGS first); the tools here are Movement I series 2's generalised pipeline (`symphony/mvt1/reaper-v621/tools/`, equal to `mockup-kit/pipeline/` at Movement I c36) plus the port's edits below.

## Files

- `mvt2-v600-mockup.rpp`: the REAPER project (a copy of series 1's, `RENDER_1X 1`; the first build rewrites every track, the tempo map and the pre-roll). 32 tracks, one Opus instance each, stems 01-32 in `build/score_config.py` `TRACKS` order (same as series 1).
- `build/`: `mockup.ly` (Movement I's extraction: one staff per player plus a DrumStaff; dumps `mockup.midi` and `mockup-events.tsv`; v600 has no trumpet or percussion notes, so those staves are silent and have no tracks), the score sources copied from v600 (`global.ily`, `parts.ily`, `score-defs.ily`, `sections/`, run through `convert-ly` to LilyPond 2.26, `\medium` -> `\normal-weight`), `score_config.py` (movement II's tables), `parts.json`, `mix.json` (series 1's c26 mix), `probe.json`, `ks_maps_extra.json`, and the per-note tables (`roles`, `note_trims`, `pitch_trims`, `entry_leads`, `early_fills`, `leg_leads`, `loop_fills`, `loop_profiles`, `rebow_fills`, `rebow_moves`).
- `tools/`: the pipeline (score_to_parts, space_rebows, build_reaper, reaper_ctl with owner "mvt2", render_cycle, measure, probe_attacks, deliver_master, motion, auto_fills, fit_rebows, fit_loops, fit_accents, fit_accent_bodies, stem_fix, rendermap). `mockup-kit/README.md` and Movement I's README ("Tools added in later cycles") describe each.
- `loop/`: `BRIEF.md` (read by every agent), `critic_prompt.md`, `actor_prompt.md`, `workflow.js`, `HISTORY.md`, `LEARNINGS.md`, `MANUAL-READING.md`, `MANUAL-GAPS.md`, `DYNAMICS-RESEARCH.md`.
- `cycles/`: `c00`-`c26` link to series 1 (read only); from `c27` on, per cycle the critics' `reports/`, `before/`, `render/`, `metrics/`, `CHANGES.md` and the delivered `mvt2-mockup-cNN.mp3`. `cycles/c27/PORT.md` and `cycles/c27/port/` record the port.
- `jobs/`: the Lua jobs and generated Opus states (`NN_<patch>.b64`; empty until the first build, so the first `--midi-only` build rebuilds every track fully).

## Rebuild from scratch

```
cd build && lilypond -o mockup mockup.ly
~/.venvs/claude-composes-reaper/bin/python ../tools/score_to_parts.py . ~/.rpr-bridge/libs/ew_ho/ks_maps.json parts.json
~/.venvs/claude-composes-reaper/bin/python ../tools/space_rebows.py parts.json --write   # when re-bows changed
~/.venvs/claude-composes-reaper/bin/python ../tools/score_to_parts.py . ~/.rpr-bridge/libs/ew_ho/ks_maps.json parts.json
cd ..
# REAPER is shared with the Movement I thread: take the lock first, keep job files in this folder
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py lock "mvt2 cNN actor"
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py start && ~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py open
~/.venvs/claude-composes-reaper/bin/python tools/build_reaper.py build/parts.json jobs
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py restart
# reopen the audio device (reaper.Audio_Init() job), then:
~/.venvs/claude-composes-reaper/bin/python tools/render_cycle.py N
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py quit && ~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py unlock
```

`score_to_parts.py` must print no WARNING (each one is a printed dynamic the CC11 curve misses).

## Port to v600 (cycle 27; details and every dropped entry in `cycles/c27/PORT.md`)

- Config: `build/score_config.py` is series 1's c26 tables (they were inline in series 1's `score_to_parts.py`; `mockup-kit/pipeline/example-config/score_config.py` holds them unchanged) fitted to v600. Every change carries a "v600 port:" comment: `TRACK_SPLITS` windows (Violoncellos div 62-66, Violins II div by rank, Violas div adds 266-269 and 279-304), `RAMP_SPANS` (the allargando from qn 216), `REBOW_AT` for the opening chord, bar 66 and Violas div's final A flat 3, `HP_TARGET_AT`/`SUBITO_AT` at bar 58, Clarinet 2's morendo target, `SCORE_TITLE` "mvt2-mockup", and the removed or moved per-onset entries.
- Generic rules: Movement I's rules stay on with their defaults, among them `AUTO_REBOW` (every string note over 4.5 s re-bowed, staggered by `tools/space_rebows.py`; `REBOW_VEL` by printed level instead of series 1's 41) and `GENTLE_ACCENT` (accents on the plain sustain with a volume swell). Movement I's movement-specific settings of generic rules (`CC1_DYN_TRACKS`, `TIMP_CC1_MAP`, `WIND_DETACH`, ...) are not copied; `loop/MANUAL-GAPS.md` #1 proposes `CC1_DYN_TRACKS` for c28.
- Extraction: `build/mockup.ly` `mockVol` turns v600's hidden MIDI-only dynamics into hairpin stops and drops the score's MIDI volume settings (`midiMinimumVolume`, `midiMaximumVolume`, `instrumentEqualizer`, `midiExpression`).
- New generic options in `tools/score_to_parts.py` (comments "mvt2 v600 port (c27)"): `SOLI_AS_META` ("4 soli" reads like "metà"), "via sord." as a mute-off word (ignored after the last note), `AUTO_REBOW_SKIP_TREM`, the re-bow keyswitch back for chord partners, `REBOW_SAME_ROWS` (Flautando re-bowed on Flautando), `SUBITO_AT`, the fp check after its spike, portato read as tenuto. `tools/stem_fix.py` scratch paths are `mvt2-stemfix-*`. `tools/reaper_ctl.py` takes the lock as owner "mvt2".
- Per-note tables: checked onset by onset (`cycles/c27/port/port_tables.py`); 89 entries dropped, 3 moved (the coda viola entry 277 -> 279), the rest kept. `probe.json`: the celli pizz. refs replaced by the basses'.
- parts.json against series 1's c26: 32 tracks, same patches and stems; 1466 -> 1526 notes; tempo map differs only at qn 212-220; new articulation rows on Clarinet 2, Bassoon 2, Horns 1/3/4, Double basses, Violoncellos div, Violas div, Horns 1-2 a2 (rows dropped on Flute 2 and Violoncellos), so those Opus states change.
