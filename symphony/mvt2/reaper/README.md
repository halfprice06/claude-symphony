# Movement II mockup in REAPER (EastWest Hollywood Orchestra Opus Edition)

First-pass mockup of `mvt2/v77`, built by script through the REAPER file bridge in `guides/reaper-claude-scripting-guide.md`.

- `mvt2-v77-mockup.rpp`: the REAPER project, set to render at 1x offline (`RENDER_1X 1`; full-speed renders start notes up to 0.6 s late). 27 tracks (since cycle 1, a separate Harp harmonics track), one per player, each with its own Opus instance and Hollywood Orchestra patch, plus the full tempo map (28 tempo/metre changes from `global.ily`, including the MIDI-only rit. steps).
- `render/mvt2-v77-mockup.wav`: the dry stereo render (48 kHz, no reverb or processing). `render/mvt2-v77-mockup.mp3` is the same with +5 dB and a -1 dBFS limiter.
- `build/`: the extraction: `mockup.ly` (one staff per player; it dumps MIDI plus an event list of articulations, text, dynamics, hairpins, slurs and tremolos), `parts.json` (what goes into REAPER) and logs.
- `tools/score_to_parts.py`: MIDI + events -> notes, keyswitches, CC lanes per track. `tools/build_reaper.py`: writes the tempo map and tracks into the running REAPER.
- `jobs/`: the Lua jobs that were run, and the generated Opus states (`*.b64`).

Mix (since cycle 1): `build/mix.json` holds per-track gain, stereo seat/width (REAPER stereo-pan mode), the Opus mics to load and their levels, and per-mic reverb sends; every patch's Opus reverb is replaced by the Violins I patch's hall. `build_reaper.py` applies it (`--mix-only` sets only volume and pan).

Since cycle 2, every track has a REAPER volume envelope that holds the track gain (REAPER ignores `D_VOL` under an envelope, so `D_VOL` stays at 0 dB), the mix.json `dyn_trim_db`/`soft_trim_db` level trims (read from the printed dynamic curve), and parts.json `vol_db` (from `build/roles.json`, `build/note_trims.json`, the final-bar fade and the timpani roll settle). `--mix-only` rewrites volume, pan and these envelopes without reloading patches. `build_reaper.py` also loads every articulation row a track uses into the KS Master state (by default only the first rows are loaded, and keyswitches to unloaded rows are ignored). ## How the patches are loaded

The guide says patch loading inside Opus is not reachable from ReaScript. It is, through the plugin state: Opus's VST3 state is gzip-compressed JSON (a `Performance` with a `zones` list), and an `.oib` patch file is the same container holding one `Instrument`. `~/.rpr-bridge/libs/ew_ho/opus_state.py` puts the patch's instrument JSON into a zone (`{"class": "InstrumentZone", ..., "instrument": <oib JSON>}`) and sets it with `TrackFX_SetNamedConfigParm(tr, 0, "vst_chunk", ...)`. Two details matter: the first 4 bytes of the state must equal the total blob length minus 16, or Opus truncates the JSON; and a zone with only a locator (no full instrument JSON) crashes Opus. The keyswitch maps in `~/.rpr-bridge/libs/ew_ho/ks_maps.json` were read from the `.oib` files, not typed in.

## Choices made without asking

| Player | Patch | Note |
|---|---|---|
| Flutes, oboes, cor anglais, clarinets, bass clarinet, bassoons, contrabassoon | the solo instrument's KS Master (Flute 2 has its own) | Oboe 2, Clarinet 2 and Bassoon 2 reuse player 1's patch |
| Horns 1-4 | Solo French Horn KS Master, four instances | Horn 3's con sord. (bar 87) is not rendered: no muted horn in the KS Master |
| Trombones 1-2, bass trombone | Solo Trombone KS Master | HO has no solo bass trombone; its D2 notes are below the tenor trombone's normal range |
| Tuba | Solo Tuba KS Master | |
| Timpani | Timpani Flt KS (felt sticks; the score asks for soft sticks) | rolls use the roll articulation; the patch has no CC11, so dynamics go on CC7 |
| Harp | Harp Maestro | the Harp KS Master's keyswitches (21-35) overlap the harp's low notes (down to E flat 1) |
| Strings | 1st/2nd Violins, Violas, Celli, Basses KS Masters | Violin I's solo in bars 17-22 is played by the section (no solo violin library on the drive) |

Articulations: slurred single lines use Leg Slur, everything else Sus; pizz./arco, tremolo (`:32`), accents and Violin II's sul tasto (Flautando) switch keyswitches. String mutes use the patches' Con Sordino control (CC15). Dynamics are on CC11, which crossfades the dynamic layers in Hollywood Orchestra (HO manual, section 2.1.3); CC1 (vibrato) follows CC11 between 40 and 100. Hairpins ramp to the next marked dynamic, or by about one dynamic level when none is marked. Mic positions are the patches' defaults (Close + Main).
