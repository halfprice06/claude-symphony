## Findings (ranked)

### 1. Score-only marks are stored in the part variables, so the parts print rehearsal letters and tempo words twice. Applied.
Bars: Vln II 37 (two "D"s and two "Poco più mosso (♩ = 60)"), 45 (two "E"s), 47 ("poco rit." twice), 48 ("poco sostenuto" twice); Vla 83 (two "K"s and "a tempo" three times). The labels "1." (Fl 1 57, Ob 1 44 and 57, Hn 1 53 and 57, Bsn 1 68) and Hn 4's "4." at 1 also appear in single-player parts, where "4." floats under the system below bar 31.
Evidence: MOLA PDF 5 says letters and bar numbers in the parts must match the score. PDF 8 says simply extracting parts does not give error-free parts. `\strMark` (global.ily) and the Vln II markups at 47–48 exist only to repeat global marks above the highest string staff in the score, when Vln I is hidden.
Fix: tag them for the score, and have the parts remove that tag.
```
% global.ily, strMark
#{ -\tag #'score -\tweak outside-staff-priority #1000 -\tweak X-offset #-1 ^\markup \column { ... } #}
% bSec.ily Vln II 47-48
\after 2 -\tag #'score ^\markup \italic "poco rit." ... fis'2-\tag #'score ^\markup \italic "poco sostenuto"
% every ^\markup \bold "1." and Hn 4's "4.":  -\tag #'score ^\markup \bold "1."
```
In `parts-book.ly`, each part is `\removeWithTag #'score \<var>`. The score keeps 'score tags, so score.pdf does not change.

### 2. No cues in any part, although nine players wait 29–62 bars before their entries. Applied for three; pattern given for the rest.
Bars: Tbn 1 rests 1–62 and enters ff marcato with the quotation at 63. Hn 2 and Ob 2 rest 1–60. Cl 1 rests 1–52. Hn 1 rests 15–52 before an exposed p entry. Fl 1 rests 1–36 before the theme-B solo. Tbn 2, B.tbn and Tuba rest 1–59. Timp rests 4–51. Cbsn rests 1–29.
Evidence: MOLA PDF 5 says logical cues are expected in long rests; they must be audible, and transposed to the reading key. Ex. 4 (PDF 10) shows a small-note "Viol. I" cue in the bars before the entry.
Fix (applied): quotes are defined in `parts-book.ly`, and the cue is written in the variable under a 'part tag beside a 'score copy of the rests.
```
% parts-book.ly
\addQuote "bassTbnQ" { \bassTbn }  \addQuote "corAnglaisQ" { \corAnglais }  \addQuote "bassClQ" { \bassCl }
% bSec.ily Tbn 1, 61-62
\tag #'score { R1*2 } \tag #'part { \cueDuring #"bassTbnQ" #DOWN { <>^\markup \tiny "B.tbn." R1*2 } } |
% bSec.ily Hn 1, 51-52 (cor anglais A♭4-G♭4-F4-G♭4, printed E♭5-D♭5-C5-D♭5 for horn in F; \transposition f is set in the horn parts)
R1*8 | R1*6 | \tag #'score { R1*2 } \tag #'part { \cueDuring #"corAnglaisQ" #UP { <>^\markup \tiny "C.a." R1*2 } } |
% trans.ily, new variable: Fl 1, 34-36 (bass clarinet lead-in to theme B)
transFluteOne = { R2.*3 | \tag #'score { R2.*3 } \tag #'part { \cueDuring #"bassClQ" #DOWN { <>^\markup \tiny "B.cl." R2.*3 } } | }
```
score.ly now passes `\removeWithTag #'part` for fluteOne, hnOne, bsnOne and tbnOne, as it already did for corAnglais and hnFour. Still to do, same pattern: Hn 2/Ob 2 at 59–60 (Fl 1/Vln I), Cl 1 at 51–52 (C.a.), Tbn 2/B.tbn/Tba at 58–59 (Vln I), Timp at 50–51 (C.a.), Cbsn at 28–29 (Vc).

### 3. Collisions in the extracted parts. Applied (layout in `parts-book.ly`).
Bars: bar 30 and bar 82, where `\after 2 \pp x2.\p\>` prints "p pp" as one cluster (Vln I, Vln II, Vla, Vc, Fl 1, Bsn 1·2, Cl, B.cl.). Bar 47, where `\after 2. \pp eis'1\mp\>` prints "mppp" (Vln II, Vla, Bsn 2, Cb). Bars 65/71: H is a 6-bar multirest, and "J" sits on the ♩ of "Tempo I (♩ = 52)" in every wind and brass part. LilyPond warned "decrescendo too small" 17 times while building the parts.
Evidence: MOLA PDF 8 and Ex. 7 (PDF 12) show exactly these errors (dynamics and a rehearsal letter colliding with text). Ex. 3 (PDF 10) shows how it should look: each hairpin has room between its two printed dynamics ("pp < > mp").
Fix, in the parts layout only:
```
\context { \Staff \override Hairpin.minimum-length = #5
  \override Hairpin.springs-and-rods = #ly:spanner::set-spacing-rods }
\context { \Score \override RehearsalMark.outside-staff-padding = #1 \override MetronomeMark.outside-staff-padding = #1
  \override RehearsalMark.outside-staff-horizontal-padding = #1 }
```
After the fix: 3 warnings remain, all in bar 47 (Bsn 2, Vln II, Cb). The whole-note bar has no note column at beat 4 to stretch. If the composer wants it clean, write the arrival as `eis'1\mp\> <>\pp` at 48 b1 in the parts, or accept the tight "mp > pp".

### 4. Harp part: the page turn falls between 79 and 80, at the f climax. Applied.
Evidence: MOLA PDF 7: allow time to turn; a multirest at the end of the page is preferred; otherwise the turn goes in a rest. The harp's only long rest after 36 is H, 65–70.
Fix: in the harp bookpart, `<< \partGlobal \removeWithTag #'score \harpR { s4*238 \pageBreak } >>`, a break before 71. Page 1 now ends with the 6-bar rest; page 2 is 71–92. Every other part fits on one page (B4, 7.4 mm).

### 5. String mutes: "senza sord." appears only at the next entry. Advance warning applied (closes the c055 open item).
Bars: Vln II, Vla, Vc and Cb are con sord. from 15/21/23 to 30; tutti Vln I from 22 to 30. Their parts say "senza sord." only at 37 (Vln I at 52). In the meantime the player has turned through 31–36 and a key and metre change.
Evidence: MOLA PDF 5 and Ex. 5 (PDF 10): the change is printed where the player stops ("to piccolo"), and the new state at the entry. Hn 3·4 already follow this ("mettere sord." at 82, "con sord." at 87).
Fix (trans.ily; the string staves are hidden in the score at 31–36, so score.pdf does not change):
```
transVlnOne = { R2.^\markup \italic "(tutti) via sord." | R2.*5 | }
transVlnTwo = { R2.^\markup \italic "via sord." | R2.*5 | }   % likewise transVla, transVc, transCb
```

### 6. Harp pedal diagrams and A♮/A♭ marks print in the harp part. Applied for the part; the score is unchanged.
Bars: diagrams at 7, 37, 53, 71; "A♮"/"A♭" at 39, 40, 55.
Evidence: MOLA PDF 5: "Harp pedaling should be left to the performer and not printed." The protection (c006/c016/c026; c068) gives as its reason that in the *score* the diagrams record the scordatura and the D♭ plan. That reason does not cover the part. The scordatura is not pedalling and stays in both.
Fix: `-\tag #'score ^\markup \small \harp-pedal #"..."` and `-\tag #'score _\markup \small "A♮"`. At 7 the scordatura text is kept for the part as `-\tag #'part ^\markup \small \italic "(lowest D string tuned to D♭)"`. score.ly passes `\removeWithTag #'part \harpL`.

### 7. Horn 1 at 60: the crescendo has no end in its own part. Also: Bsn 1's pickup at 78 has no dynamic (closes the c068 open item). Applied, part-only.
Bars: Hn 1 `es'4\< f'4 ges'4 f'4` at 60, then rests to 66. In the score, Hn 2's f at 61 ends the shared staff's hairpin. In the Hn 1 part, the hairpin is drawn across 61–64 to H. Bsn 1 enters on 78 b3 (`r2 c'4(`) after seven bars' rest with no dynamic. It doubles Hn 1·2, which enter p< there. On the shared staff Bsn 2 sits at f, so a printed p would contradict it.
Evidence: MOLA PDF 8 ("through the eyes of a player"); Ex. 3 (PDF 10): every entry after a rest has its own dynamic, and hairpins run from one level to another.
Fix:
```
\partCombineAutomatic R1*4-\tag #'part \! |          % bSec Hn 1, 61
aTwoBsnOne = { R2.*7 | r2 c'4(-\tag #'part \p -\tag #'part \< | des'4\ff ...
```
Both are part-only. I tried `\after 4 \!` on the note first. That changed the part combiner's state, and the score then printed "1. solo" twice at 67, so I used the tagged form.

### 8. Horn 1's part does not say "solo" at 6. Applied.
In the score, "1. solo" comes from the part combiner's `soloText`, which does nothing in a one-player part. The Hn 1 part shows only "dolce espr." for the movement's first theme statement.
Evidence: MOLA PDF 8; Ex. 5 (PDF 10) names the instrument and role at the entry.
Fix (intro.ily): `es8(\p-\tag #'score ^\markup \italic "dolce espr." -\tag #'part ^\markup \italic "solo, dolce espr." f8`.
