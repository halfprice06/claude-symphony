## Findings

### 1. Tempo marks are not repeated over the brass on the full systems (applied)
Bars 1, 60, 61, 64. On the four full systems the tempo word appears above the flutes and above Violin I, with 15 or more staves between them; the horns, trombones and tuba read none. At 63–64 the trombone 1 quotation is the one solo line in the bar, and the "allargando" at 64 that shapes its tail is printed 7 staves above it and 9 staves below it. Adler PDF 294: "It is strongly urged that tempo markings be placed at the top of the score and repeated in the space separating each choir"; Ex. XVIII-1 (PDF 293) prints "Allegretto ♩ = 100" four times on one page. The scherzo and finale already do this.
Fix (score.ly; a spacer voice in the Horns 1·2 staff, so the marks vanish with that staff on reduced systems):
```
brassMark = #(define-event-function (tempo) (markup?)
  #{ -\tweak outside-staff-priority #1000 ^\markup #tempo #})
brassLetter = #(define-event-function (letter tempo) (string? markup?)
  #{ -\tweak outside-staff-priority #1000 -\tweak X-offset #-1 ^\markup \column { \override #'(box-padding . 0.5) \box \bold \fontsize #3 #letter #tempo } #})
brassMarks = {
  \once \override TextScript.X-offset = #-5.2 s2.\brassMark \markup { \bold "Adagio" \concat { "(" \fontsize #-2 \general-align #Y #DOWN \note {4} #1 " = 52)" } } s2.*35 |
  s1*23 | s1\brassMark \markup \medium \italic "poco allargando" |
  s1\brassLetter "G" \markup { \bold "Largamente" \concat { "(" \fontsize #-2 \general-align #Y #DOWN \note {4} #1 " = 54)" } } | s1*2 |
  s1\brassMark \markup \medium \italic "allargando" |
}
...
<< \global \new Voice \brassMarks \pc \removeWithTag #'part \hnOne \removeWithTag #'part \hnTwo >>
```
The marks match the top and string marks in font and horizontal position (checked at 200 dpi). Reduced systems are left alone: their brass staff is at most four staves below the top mark, and doubling it there would only add clutter. Score-only; parts and MIDI notes unchanged (the MIDI has one fewer empty track; every note, time and velocity is identical).

### 2. Single-staff choirs print without a bracket (applied)
Hn. at 7–14, 53–56, 75–78; Cbn. and Hn. 3·4 at 23–30; C.a. at 49–52; Bn. and Hn. at 65–70; Cl. at 83–86. LilyPond hides a StaffGroup bracket shorter than 5 staff spaces, so on these reduced systems a choir with one printed staff has no bracket, and on page 5 (65–70) Bn., Hn. and Timp. stand as three unbracketed staves above the strings. Adler PDF 291 item 2 (the separation of choirs "must be immediately discernable"), PDF 294 ("heavy brackets set off the choirs"). Movement I fixed the same thing in its c165.
Fix (score.ly \layout): `\context { \StaffGroup \override SystemStartBracket.collapse-height = #1 }`.

### 3. The timpani are not bracketed as a choir (applied)
Every system with timpani. The timpani staff sits outside every StaffGroup, so it has no bracket, unlike the woodwind, brass and string choirs and unlike movement I and the scherzo. Ex. XVIII-1 (PDF 293) brackets "6 Timpani, Xylophone, Triangle, Snare Drum" as their own choir; PDF 292 asks for a separate space for the percussion.
Fix (score.ly): wrap the Timpani staff in `\new StaffGroup \with { \remove "Span_bar_engraver" } << ... >>` (as movement I, c165).

### 4. No family sub-bracket for the horns and the trombones (applied)
Brass staves on every full system and on 79–82 (Hn 1·2 with Hn 3·4). Adler PDF 294: "heavy brackets set off the choirs; and an additional brace clarifies instruments of a family"; Ex. XVIII-1 joins Horns I–II with III–IV and the three trombones. Here Hn 1·2/Hn 3·4 and Tbn 1·2/B.tbn. are only inside the general brass bracket. The scherzo uses square sub-brackets (its c145).
Fix (score.ly): wrap the two horn staves, and the Tbn 1·2 and B.tbn. staves, each in
`\new StaffGroup \with { systemStartDelimiter = #'SystemStartSquare \override InstrumentName.padding = #1.2 } << ... >>`.
The sub-bracket collapses when only one horn staff is printed (default collapse-height for SystemStartSquare), so reduced systems show the main brass bracket only.

### Recorded, no change
- Choir spacing (PDF 292, "an empty line between the choirs"): the default staffgroup spacing gives only slightly wider gaps between choirs. With findings 2–4 the brackets now mark every choir, and widening the gaps would put the dense pages 4, 5 and 7 at risk; not raised.
- Brahms Ex. XVIII-4a puts a dynamic or "cresc." under every staff; this score does the same on shared staves, one set per staff (the shared-staff dynamic rule stays).
- Reduced-score slashes, names in every system, choir order, keys, drum count, muta placement and key/time signatures all follow (table rows 5–7, 9, 14, 17, 19, 20).
