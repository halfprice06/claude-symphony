# Movement I mockup in REAPER (EastWest Hollywood Orchestra Opus Edition)

Mockup of `symphony/mvt1/v621` (Symphony No. 1 in C minor, I. Lento — Allegro appassionato), built by script through the REAPER file bridge and improved by the actor-critic loop in `loop/`. This folder is local and kept out of git; the method and tools come from `mockup-kit/` (read its README and LEARNINGS first), which came from the movement II mockup (`symphony/mvt2/reaper/`).

## Files

- `mvt1-v621-mockup.rpp`: the REAPER project (main pass), 33 tracks (one Opus instance each; Horns a2 since c13; a 34th, "Cello solo", was tested in c35 and removed on memory; since c40 it plays in the second pass); `mvt1-v621-mockup-pass2.rpp` (c39): the second-pass project, stems 34 on (c42: 7 tracks, stems 34-40) (see "Second render pass"), the tempo map with the 3 qn pre-roll, `RENDER_1X 1` (1x offline render).
- `build/`: `mockup.ly` (one staff per player plus a DrumStaff; dumps `mockup.midi` and `mockup-events.tsv` with every note, drum stroke, articulation, text, dynamic, hairpin, slur and tremolo in quarter notes), the copied score sources (`global.ily`, `parts.ily`, `sections/`, run through `convert-ly` to LilyPond 2.26), `score-defs.ily`, `score_config.py` (this movement's tables, see below), `parts.json` (what goes into REAPER), `mix.json`, `probe.json`, `ks_maps_extra.json`, and the per-note tables (`roles`, `note_trims`, `pitch_trims`, `entry_leads`, `early_fills`, `leg_leads`, `loop_fills`, `loop_profiles`, `rebow_fills`; empty at cycle 0; `accent_fits` from c07).
- `tools/`: the pipeline (copied from `mockup-kit/pipeline/` and generalised, see below).
- `loop/`: `BRIEF.md` (read by every agent), `critic_prompt.md`, `actor_prompt.md`, `workflow.js`, `HISTORY.md`, `LEARNINGS.md`, `DYNAMICS-RESEARCH.md`.
- `cycles/cNN/`: per cycle the critics' `reports/`, `before/` (tools and data snapshot), `render/` (master and stems), `metrics/`, `CHANGES.md` and the delivered `mvt1-mockup-cNN.mp3`.
- `jobs/`: the Lua jobs and generated Opus states (`NN_<patch>.b64`).

## Rebuild from scratch

```
cd build && lilypond -o mockup mockup.ly
~/.venvs/claude-composes-reaper/bin/python ../tools/score_to_parts.py . ~/.rpr-bridge/libs/ew_ho/ks_maps.json parts.json
# REAPER running with the bridge (open -a REAPER --args -new), the project open:
~/.venvs/claude-composes-reaper/bin/python ../tools/build_reaper.py parts.json ../jobs
```

Then save, quit, restart REAPER, open the project, and `tools/render_cycle.py N`.

### Second render pass (from c39)

Tracks listed in `PASS2_TRACKS` (`build/score_config.py`; parts.json `"pass": 2`) live in a second REAPER project,
`mvt1-v621-mockup-pass2.rpp`, so they cost the main project no memory (it settles at about 46 GiB of the brief's 45).
`build_reaper.py` leaves them out of the main project and builds only them with `--pass2`. Until c49 the reverb was
inside each Opus instance, so every stem was self-contained; from c50 (the EastWest template mix) the reverb is on REAPER
return tracks fed by post-fader sends, each project has its own returns, and `render_cycle.py --pass2` sums each pass-2
return stem with the main project's (`render/91..94`), so the two passes still sum in float. Both projects use the same
`build_reaper.py`, `mix.json` (returns, sends, mics written per group, seats, EQ), tempo map, 3 qn pre-roll and reset
lanes. After the main
render (above) and `reaper_ctl.py quit`:

```
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py --pass2 create     # once: main header, no tracks
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py start
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py --pass2 open
~/.venvs/claude-composes-reaper/bin/python tools/build_reaper.py build/parts.json jobs --pass2   # tempo map + pass-2 tracks
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py --pass2 restart
~/.venvs/claude-composes-reaper/bin/python tools/render_cycle.py N --pass2
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py --pass2 quit
```

`render_cycle.py N --pass2` checks memory and the audio device as for the main pass, renders into
`cycles/cNN/render_pass2/`, cuts the pre-roll, copies each stem into `cycles/cNN/render/` under its parts.json stem
number (34 on), keeps the main pass's master as `render_pass2/00_Master_main.wav`, rebuilds `render/00_Master.wav` as
the float sum of all stems, then measures and delivers (memory in `metrics/memory_pass2.txt`). `stem_fix.py` and
`render_cycle.py N --measure-only` then work on the combined folder as before. Later `--midi-only` / `--mix-only`
builds of a pass-2 track need `--pass2` and the pass-2 project open.

Pass-2 tracks are usually `ALIAS_TRACKS`: built by `score_to_parts.py` under a main track's name over listed windows
(the main track rests there through `TRACK_WINDOWS`), so every per-track rule and table of that track applies, on the
same or another patch. c39: "Trumpets a2" (2TP KS Master, the Trumpet 1-2 unisons at 520-525 and 664.5-679) and the
fugato staccato windows of Bassoon 1, Cor anglais and Flute 1 on their "Stac DblTng RRx9" rows ("... stac"). c40: "Cello solo" (stem 38), the coda "Solo espr." (680-696) on Celli KS Master DIV A, an alias of Violoncellos
fitted fresh ("drop" / "set" alias keys; leads, a level contour and join rows in its alias "tables"); Violoncellos rests
there. A pass-2 track that is deleted from parts.json must also be deleted from the pass-2 project (render_cycle.py maps
every rendered stem to a parts.json track; `cycles/c40/del_tracks.lua`). Opus saves controller state into each instance
(LEARNINGS c40): after a controller test, fully rebuild the instance (`build_reaper.py build/parts.json jobs "<track>"`).
A/B test tracks go in `TEST_TRACKS` (c41): rendered in pass 2, their stems land in `cycles/cNN/test_stems/` and stay out
of the master; delete them from parts.json and from the pass-2 project once the test is decided.

## What differs from the movement II pipeline (cycle 0)

- Movement-specific tables are no longer inside `score_to_parts.py`. `build/score_config.py` is run in the module's namespace after the generic defaults: `TRACKS`, `SCORE_END`, `SCORE_TITLE`, `PERC_MAP`, `RAMP_SPANS`, and any per-onset table (`LEAD_SPANS`, `JOIN_NOTCH`, `ACCENT_*_AT`, `REBOW_AT`, ...). The final fade, tail hold and render end use `SCORE_END` (qn 728) instead of movement II's qn 304. The movement II tables are in `mockup-kit/pipeline/example-config/score_config.py` and reproduce its parts.json exactly.
- New track families: three trumpets on the Solo Trumpet KS Master (`1TP KS Master`; its sustain rows are "Sus Non Vib MAX"/"Sus Vib MAX", reached through `KS_ALIASES`), and percussion (`family "perc"`, `build_perc_track`): tam-tam, suspended cymbal and crash cymbals, one patch each, notes from the drum events of `mockup-events.tsv` (`mockup.ly` logs drum-type), velocity from the printed dynamic, at least `min_s` seconds of ring.
- `AUTO_REBOW` (Dan's movement II note on a held chord): every string note over `REBOW_MAX_S` (4.5 s) is split at output into same-pitch Sus MAX re-bows about `REBOW_SEG_S` (3.1 s) apart, with a per-track phase and length so sections never change bow together; a note joined into the next one hands back to that note's articulation with a keyswitch 0.02 qn before it. Re-bow velocity follows the printed level (`REBOW_VEL_BY_CC`).
- `GENTLE_ACCENT` (Dan's note on harsh trombone accents): brass accents play plain Sus (no accent sample, no CC11 bump, no added velocity) with a volume swell (+4 dB at f and louder, +2.5 dB softer; full at +0.07 s, held to +0.25 s, gone by +0.6 s).
- `render_cycle.py` finds the work folder from its own path, the `.rpp` by glob, the render end from `parts.json` `score_end`, and names the mp3 from `title`. `probe_attacks.py` reads its checks from `build/probe.json`; `auto_fills.py` reads its track lists from `build/auto_fills.json` when present.
- `mix.json` starts from movement II's c26 mix (hall, mics, seats, EQ, soft trims) with the mvt II-only tracks, qn-keyed loud EQs and the horn mute EQ removed; new groups `trumpet` and `perc`.

The tables of cycle 0 are described here; `cycles/cNN/CHANGES.md` and `loop/HISTORY.md` record later changes.

## Tools added in later cycles

- c01: `tools/fit_rebows.py PREV PARTS [--write]` fits `build/rebow_fills.json` for every re-bow from a render; `score_to_parts.py` lists each string track's re-bows in parts.json (`rebows`: [qn, end of the split note, pitch]). `tools/stem_fix.py N OLD_BUILD NEW_BUILD [--apply]` applies a level-only data change (volume envelope: roles, trims, fills, gains, dyn/soft trims) to the rendered stems with build_reaper's `vol_points()` and rebuilds the master as the float stem sum (originals to `cycles/cNN/render_first/`); then `render_cycle.py N --measure-only` re-measures and re-delivers, and `build_reaper.py --mix-only` puts the same data into REAPER. `build/auto_fills.json` lists the lead-line tracks for `auto_fills.py`.
- c02: `fit_rebows.py` refits on a render that already carries shapes (it takes the old shapes, from `build/rebow_fills.json` as it is when it runs, out of the plan and the stem), starts each fill 0.12 s before its re-bow, and takes `--hold-max-after QN:DB`. `tools/fit_loops.py PREV PARTS "Track:onset[:period]" ... [--write]` fits periodic inverse loop profiles into `build/loop_profiles.json` (the c02 profiles landed early and were removed: see `cycles/c02/CHANGES.md`). `build_reaper.vol_points` reads optional "mp"/"mf" anchors in `soft_trim_db`. `deliver_master.py` ride ratio 2.5. New generic rules in `score_to_parts.py`: `FFF_HOLD_CAP`, `HP_CHAIN_RISE_FFF`, `NM2_STOP_SOFT`, `ACCENT_MINUS_HPGAIN`, `DETACH_ACCENTS`, `STR_ACC_AFTER_SUS`, `GENTLE_ACCENT["string"]`; a note with listed `REBOW_AT` points keeps its keyswitch back.
- c01 rules in `score_to_parts.py`: subito dynamics (`SUBITO`), woodwind `GENTLE_ACCENT` with `keep_legato`, `SHORT_SUS_TO_LONG` (a slur's short first note into a long note stays on Leg Slur MAX), `PERC_MAP` `vel_min`.
- c03: `tools/build_reaper.py` `tempo_job` gives the pre-roll marker its own meter (3/4 for the 3 qn pre-roll) and stops the build when any tempo marker is off its qn. Before, the pre-roll carried the score's 4/4, REAPER moved the score's first marker from 3.0 s to 4.0 s, and every event from score qn 1 on sounded 1/6 qn early (renders c00-c02). `tools/rendermap.py` with `build/render_shift.json` gives the file time of a score qn in those old renders; `fit_rebows.py`, `auto_fills.py`, `fit_loops.py`, `measure.py`, `probe_attacks.py` and `stem_fix.py` use it. `probe_attacks.py` searches from 0.3 s before the onset (an early note reads negative).
- c03: `tools/space_rebows.py PARTS [--min-piece 1.2] [--write]` moves automatic re-bow points so that no two string sections re-bow within 0.6 s (`build/rebow_moves.json`, read by `score_to_parts.py`; parts.json `rebows` rows are now [qn, note end, pitch, piece start, automatic point]); it moves fitted shapes in `build/rebow_fills.json` with their points, also when a point moved with its note. Run order: score_to_parts -> space_rebows --write -> score_to_parts.
- c03 rules in `score_to_parts.py`: `SHORT_SUS_JOIN` (a fast-slur Sus MAX eighth that overlaps the next legato note makes it a legato target with lead; Leg BC MAX across a slur boundary), `ENTRY_LEAD_ART_S` (extra entry lead by articulation), `TIMP_DELAY_S` (timpani strokes 0.06 s after the score onset) and `PERC_MAP` `delay_s`, `ART_SPANS` (articulation tests over listed spans), negative `pre_s` in `early_fills.json` (the fill starts after the onset).
- c04 rules in `score_to_parts.py`: `REP_SPLIT` (written-out unslurred repeated string notes at 100 bpm or faster, each 1.5 qn or shorter, are separate strokes: Sus MAX at the re-bow velocity, Stac under 0.2 s, instead of one merged legato note with CC11 notches), `PORTATO_JOIN_AT` (listed slurred tenutos join on the legato row with a portato notch instead of a Sus re-tongue), `TIMP_ROLL_RESTRIKE` (listed long timpani rolls split at output into abutting same-pitch roll pieces of irregular 2.5-3.3 s length; parts.json `restrikes`), `SF_ARRIVAL_AT` (an sf that is an arrival: the spike reaches the listed dynamic and the level after it is that dynamic - 8 CC). Movement I now sets `LEAD_SPANS`, `HP_SOFT_EXTRA_SPANS`, `PHRASE_ARCS` and `TEMPO_PUSH` in `build/score_config.py`.
- c05 rules in `score_to_parts.py`: `SLUR_REP_MERGE_SUS` / `WIND_SLUR_REP_MERGE` (a same-pitch note at the end of a slur merges into the note before it with a small CC11 notch; strings keep the short_sus eighth on Sus MAX, winds the legato note, whose transition velocity keeps the eighth's own length; parts.json `slur_rep_merged`), `STR_SHORT_AFTER_SUS` (an unslurred short string note after a Sus MAX / stroke note is a fresh Sus MAX stroke at the re-bow velocity, checked in order so that runs of such notes all become strokes; parts.json `short_strokes`), `SHORT_SUS_LEAD_S` with `SHORT_SUS_LEAD_TRACKS` (a test: slurred short_sus notes start early), `BREATH_SPLIT_AT` (listed long wind/brass notes split at output into staggered same-pitch pieces with a short volume dip at each re-entry; parts.json `breath_splits`), `META_DB` ("metà" on a string part: -3 dB until "tutti"/"unis."/"div."). `build_perc_track` now applies `roles.json` rows (before c05 the percussion tracks ignored them).
- c06 rules in `score_to_parts.py`: `DOWNBOW_STROKE_AT` (listed string notes are fresh Sus MAX strokes on the Leg -> Sus entry path; the next note joins from the stroke as a Leg BC legato target; parts.json `down_strokes`), `WIND_REP_RETONGUE` (unslurred same-pitch wind/brass repeats end min(gap_s, frac x length) early with a CC11 fall over the last fall_s, back at the next onset; `cc_falls` rows take an optional return length; parts.json `rep_retongued`), `TENUTO_SWELL_DB` (slurred loud string tenutos joined as legato targets keep +1.5 dB; `tenuto_swell`), `ARRIVAL_WEIGHT_AT` (a held-back crescendo top and a short lift at listed tutti arrivals; `arrival_weight`), `LEVEL_SHAPES` (exact level shapes per track or `_all` from the config), `PT_OFF_IN_CRESC` (phrase-top contours off inside every crescendo), `SHORT_SUS_LEG_TRACKS` (test: slurred 0.20-0.25 s string notes stay on Leg Slur MAX), `ACC_SRC_EXTRA`/`ACC_PLAIN_WIN` with `GENTLE_ACCENT[family]["vel_add"]` (accent velocity at the plain level; off: the KS Master sustain rows ignore velocity, c06). `build_perc_track`: `PERC_MAP[track]["_damp"]` = [(qn, dB, s)] fades a ringing stroke at a printed damp (needs `tail_hold: false` in mix.json for that track when the damp falls after the note-off).
- c07 rules in `score_to_parts.py`: `build/accent_fits.json` (`ACCENT_FITS`: per-accent fitted swell dB or [swell, step trim] on GENTLE_ACCENT families; parts.json `acc_fitted`, `acc_trimmed`), `ROW_TRIM_DB` / `ROW_TRIM_NEAR_QN` / `ROW_TRIM_SKIP` (string Sus/Stac row level offsets in lines mixed with Leg rows; `row_trimmed`), `WIND_REP_RETONGUE_BY` / `WIND_REP_RETONGUE_SHORT`, `BREATH_FALL_BY`, `TIMP_CHAIN_BUMP_AT` (a chained roll gets no loud-attack bump unless a louder printed dynamic starts on it; `timp_chain_skip`), `TIMP_METRIC_VEL`, `SHORT_SUS_LEAD_KEEP_OVERLAP`, `SHORT_SUS_LEG_SKIP`, a third `ENTRY_LEAD_S` value for CC11 51-80 at `ENTRY_MID_MIN_BPM` or faster; `build_perc_track` reads `LEVEL_SHAPES`; `ABUT_LEAD` skips notes that AUTO_REBOW splits; `smooth_tempo` holds a rit. ramp's start tempo until the printed steps fall below it; `phrase_arcs` warns when an arc ends on a ramp start. A per-onset `ACCENT_DB_AT` level on a gentle family keeps the gentle swell shape.
- c07: `tools/fit_accents.py PREV RENDERED_PARTS [--family brass] [--write]` fits `build/accent_fits.json` from a render: each accent's level (+0.05..+0.35 s) against up to two unaccented same-dynamic neighbours each side within 2.5 qn, the volume envelope's share separated from the samples', iterated over rebuilds of parts.json until every predictable accent sits in 2-4 dB (target 3); prints 2-5 kHz first-80-ms minus body. Level only, so a refit can be applied with `stem_fix.py`. `tools/deliver_master.py` ends the mp3 1.0 s after the last 50 ms window above -65 dBFS (0.5 s fade); the wav render keeps its +8 s.
- c08 rules in `score_to_parts.py`: `ARRIVAL_WEIGHT_AT` takes an optional hold-back length (qn); `TREM_JOIN` / `TREM_JOIN_LEAD_S` / `TREM_JOIN_OVERLAP_QN` (tremolo chords joined like the sul tasto pads) with `TREM_SPLIT` (held tremolo notes split into seeded pieces at the output stage, skipped by AUTO_REBOW; parts.json `trem_splits`); `METRIC_BOWED` / `METRIC_BOWED_DB` / `METRIC_BOWED_MAX_QN` / `METRIC_BOWED_REP` and `METRIC_TIMP_DB` (the METRIC_DB level steps on short unslurred bowed notes and loud felt timpani strokes); note trims apply once per onset. `tools/fit_accents.py` runs on any gentle family (`--family string|wind|brass`), skips a slur's short first note as a neighbour (`--pickup-qn`), and keeps long and crescendo-arrival accents free of negative steps (`--keep-long-qn`). `tools/deliver_master.py` adds a slow top ride (`TOP_ABOVE`, `TOP_RATIO`).
- c09 rules in `score_to_parts.py`: `CC1_DYN_TRACKS` / `CC1_DYN_MAP` / `CC1_HOLD` (patches whose dynamic layers are crossfaded by CC1, the Hollywood Brass KS Masters and the Clarinet KS Master, take CC1 from the printed dynamic curve; constant CC1 per track), `HP_SHORT_S` / `HP_STEP_SHORT` / `HP_SHORT_KINDS` / `HP_SHORT_RET_QN` (short untargeted decrescendos move at most 6 CC; the next untargeted crescendo returns to the level before), `PORTATO_JOIN_NOTCH` (per-track portato notch), `TREM_ENTRY_LEAD_S` (tremolo entries after a held note start early; parts.json `trem_entries`). `tools/build_reaper.py vol_points` reads an optional `fff` anchor (CC 124) in `dyn_trim_db`.
- c10 rules: `score_to_parts.py` `find_unisons` keeps the copy with the louder printed dynamic first (`UNI_BY_DYN`; the last printed mark on each copy's own staves), then slurred, then longer; `build/loop_fills.json` entries may be negative (a cut on a sample bloom; overlapping bumps take the value of larger size); `NOTCH_SKIP` is used for printed bow changes that an automatic re-bow just before already plays. `tools/fit_accents.py` protects notes of `--keep-long-qn` or longer (`>=`; run with 1.4 so dotted quarters that end early are protected). `tools/deliver_master.py` caps the slow quiet-passage lift by a lift computed from each frame's own loudness (`FAST_CAP_ABOVE` 4 dB over the knee, S smoothed over 1 s), so short loud passages next to soft ones no longer inherit their lift.
- c11: `score_to_parts.py` `phrase_arcs()` takes depth "open" (push only, no slowing); `FP_SPIKE` (an fp is an f attack held 0.12 qn, at p by 0.25 qn); `WIND_REP_AFTER_SLUR` (an unslurred repeat after a slur's last legato note is re-tongued); `HARP_RING_S` / `HARP_DAMP_TEXT` / `HARP_DAMP_STAFF` (harp notes ring past their written end, cut at "étouffez" marks; needs a short release in the patch). `build_reaper.py` reads `env_release_ms` per track in mix.json and sets every AHDSR release in the Opus state (Harp 200 ms). `build/score_config.py` lists every re-bow point of the c10 build in `REBOW_AT` (`_REBOW_FROZEN`), so tempo changes no longer move re-bows; a new automatic point appears only on a note that has none listed.
- c12: `score_to_parts.py` `TIMP_CC1_MAP` / `TIMP_CC1_PAD_QN` / `TIMP_ROLL_TRIM_DB` (the felt timpani Rls row crossfades eight dynamic layers on CC1; the rolls get a CC1 lane from the printed curve and per-dynamic level trims in the volume envelope), `WIND_DETACH` (unslurred wind/brass note changes end min(gap_s, frac x length) early, per-family `by`), `GENTLE_ACCENT[family]["cc1_front"]` (CC, hold_s, ramp_s[, pre_s]): a CC1 lift at the front of loud brass accents (a test; parts.json `cc1_fronts`). `tools/auto_fills.py` caps new and raised fills inside a printed decrescendo (`DECRESC_UNDER_DB`; `--guard-existing` also lowers existing fills).
- c13: a 33rd track, "Horns a2" (2FH KS Master, stem 33), plays the Horns 1-2 unison passages; `TRACK_WINDOWS` values may be a list of windows (`([(q0, q1), ...], keep_inside)`; helpers `tw_spans`, `tw_keep`, `tw_end` in `score_to_parts.py`). New generic rules in `score_to_parts.py`: `MEAS_TREM` (a measured tremolo, value 16 or 8 with a subdivision of 0.1 s or more, is expanded into repeated notes that take the `REP_SPLIT` stroke path; parts.json `meas_trem`) and `GENTLE_ACCENT[family]["swell_s_leg"]` (the swell shape for accents played as legato targets). `tools/fit_accents.py` takes `--pickup-over DB` (an accent must also stand this far over a short pickup that ends at it; `--pickup-max-qn`, `--pickup-cap-over`) and skips tracks the measured render does not have.
- c14: new generic rules in `score_to_parts.py`: `SLUR_PAIR_RELEASE` (the second note of a two-note slur, at most 1 qn, unaccented, not in a crescendo, falls 2.5 dB from its moved onset + 0.10 s; parts.json `pair_release`), `WIND_DETACH` "fall_cc"/"fall_s" (a CC11 fall at the end of tongued notes of at most `WIND_DETACH_FALL_MAX_QN`), `MEAS_TREM["rr_runs"]` (CC36 round-robin resets at run starts; a new parts.json lane `cc36`, written by `build_reaper.py` with the other CC lanes). Run `build_reaper.py` from the work folder with `jobs` as the jobs directory (`build/parts.json jobs ...`): the `.b64` state cache that `--midi-only` compares against is `jobs/`, and a different directory makes every track a full rebuild.
- c15: new generic rules in `score_to_parts.py`: `SLUR_START_SUS` (a slur's short first note after a tongued note plays the Sus row; the second note joins from it with the `SOST_JOIN_LEAD_S` lead; parts.json `slur_start_sus`, `slur_start_joins`), `RETONGUE_LEAD_S` / `RETONGUE_LEAD_CAP` (wind/brass re-attacks after short gaps start early, the previous note ends as much earlier, its CC11 falls move with it; `retongue_leads`), `WIND_DETACH` "dip_db"/"dip_fall_s"/"dip_min_cc" with `WIND_DETACH_DIP_MAX_GAP_S` (a volume dip at tongued changes with short played gaps; `detach_dips`), `MEAS_TREM` "alt_row"/"alt_share"/"alt_seed"/"alt_max_run"/"alt_db" (seeded alternation of two stroke rows; `meas_trem_alt`), `UNI_DELAY_OVERLAP_QN` / `UNI_DELAY_FADE` (now settable from the config; `uni_fades`). `build_reaper.py vol_points`: `SOFT_DECRESC_HOLD_MAX_CC` / `SOFT_DECRESC_KEEP` (inside a soft decrescendo the soft trim keeps only part of its rise). `auto_fills.py` retimes existing fills whose hole minimum comes before the fill is full ("retimed", every measured track). `fit_accents.py` puts no negative step on a legato target moved more than 0.05 s early. `stem_fix.py --old-src FILE` takes the `build_reaper.py` a render was made with, when `vol_points()` has changed since; the render-time copy is kept in `cycles/cNN/rendered_build/`.
