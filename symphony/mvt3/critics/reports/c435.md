## Findings

### 1. 114-132: five uncued entries after 13-18 bars of rest in the G-major passage (applied)
**Problem.** H (115) to J (135) is 20 bars with no letter, and the key change at 123 is the only landmark. Five players come back in that stretch after long rests, and their parts show nothing to listen for: Fl 1 enters mp at 129 after 15 bars (114-128); Hn 1 enters pp at 127, a held solo E4, after 13 bars; Hn 3 and Hn 4 enter p < at 129 after 15 bars; Ob 1 enters f at 131 after 17 bars; the timpani enter at 132 after 18 bars (114-131). Every comparable entry elsewhere in the movement already has a cue (c075, c105, c225, c255, c345: Hn 2 at 75 and 195, Fl 1 at 61 and 181, Cbsn at 87, brass at 35, 91, 143 and 199).

**Evidence.** MOLA PDF 5: "Logical cues are expected during long periods of rest, the cues being transposed to the reading key of the instrument. Cues must be audible and obvious." Example 4 (PDF 10) shows the cue named ("Viol. I") at the end of the rest. Adler2 PDF 299 item 6: cues "facilitate re-entry after a long period of rest"; name the instrument; small notes; transposed.

**Fix (applied, part-only, tag 'part; score and MIDI unchanged).** Cue sources chosen for what is actually heard in the two bars before each entry: Bn 1's dolce solo at 125-126 (E3 F♯3 G3 | C4 D4 A3); Cl 1's mf phrase at 127-128 (C5 E5 | D5 C5 B4 A4), which leads into Fl 1's B5; Vln I at 129-130 and its run at 131 into 132. In sections/dev.ily:
```
devFluteOne: R1*6 | b''2(\mp   ->  R1*4 | \tag #'score { R1*2 } \tag #'part { \cueDuring "clOne" #UP { R1*2^\markup \tiny "Cl. 1" } } | b''2(\mp
devHnOne:    R1*13 | e'1\pp    ->  R1*11 | \tag #'score { R1*2 } \tag #'part { \cueDuring "bsnOne" #UP { R1*2^\markup \tiny "Bn. 1" } } | e'1\pp
devHnThree, devHnFour: R1*6 |  ->  R1*4 | \tag #'score { R1*2 } \tag #'part { \cueDuring "clOne" #UP { R1*2^\markup \tiny "Cl. 1" } } |
devOboeOne:  R1*8 | fis''2\f   ->  R1*6 | \tag #'score { R1*2 } \tag #'part { \cueDuring "vlnOne" #UP { R1*2^\markup \tiny "Vln. I" } } | fis''2\f
devTimp:     R1*8 | R1 | g,4->\f -> R1*7 | \tag #'score { R1*2 } \tag #'part { \cueDuringWithClef "vlnOne" #UP "treble" { R1*2^\markup \tiny "Vln. I" } } | g,4->\f
```
plus one new quote source after `\addQuote "bsnOne"` in parts-head.ily (and the same line in score.ly so the two stay in step): `\addQuote "clOne" { \removeWithTag #'part \clOne }`.
The horn cues use plain `\cueDuring`, so the horn's `\transposition f` writes them at horn pitch (Bn 1 shows as B3 C♯4 D4 | G4 A4 E4, Cl 1 as A5 G5 B5 | A5 G5 F♯5 E5). My first build used `\transposedCueDuring ... c` as in clos.ily, and that put the bassoon cue an octave low (B2, five ledger lines), so I changed it. The timpani cue shows the violins in a treble cue clef and returns to bass clef before 132. Hn 2 at 130 and Bn 2 at 131 got no cue, because each stand partner (Hn 1, Bn 1) plays through the bars before.

### 2. 221-247, cor anglais and bass clarinet parts: Q's "molto cantabile" stood next to P's metronome mark (applied)
**Problem.** In both parts the rest after P (cor anglais 223-234, bass clarinet 224-234) is narrower than "P Maestoso (𝅗𝅥 = 56)". LilyPond therefore stacked Q's two-line mark above P's, and Q's second line "molto cantabile" landed directly beside P's "(𝅗𝅥 = 56)", 1.5 mm from the minim stem, where it reads as part of Maestoso. The cor anglais's last line also held eight rests under three tiers of marks (221-279).

**Evidence.** MOLA PDF 8: extracted parts must be proofread because "anchored" markings collide or float (Example 7, PDF 12). Example 4 (PDF 10) sets each letter and tempo word in one row over its own rest. PDF 7: keep the amount of music per system consistent.

**Tested and declined.** (a) Letting tempo marks and letters take horizontal space, as the percussion part has done since c195. This puts every mark in one row, but it pushed the notes of bars 1, 223 and 273 well away from their barlines. (b) Widening only the rest at 223 with `MultiMeasureRest.minimum-length`. In a 3-line test file the override widened a rest, but in these two parts it did not take effect at 223/224 (it did at bar 7).

**Fix (applied, parts-book.ly only).** Line breaks, in the way c195 broke the cor anglais before 205. Cor anglais: `{ s1*204 \break }` becomes `{ s1*204 \break s1*30 \break s1*20 \break }`, which gives 205-234 / 235-254 (Q, stringendo, R) / 255-279 (S, allargando, T). Bass clarinet: a new element `{ s1*234 \break }` in its `<< >>`. P now ends its line alone and Q starts the next. Both parts remain one page.
