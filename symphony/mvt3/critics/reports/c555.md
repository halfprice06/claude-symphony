## Findings

### 1. Cb 277.1–2: a two-pitch group with the odd note furthest from the beam is sloped (applied)

Bars: 277, basses, first half (`c,8 c,8 c,8 g,,8`, `\stemUp`).

Problem: three C's and a final G, stems up. The G is the note furthest from the beam. Gould PDF 37 ("two pitches only in a group of three or more notes") says the beam is horizontal in that case, and slopes only when the single note is the one closest to the beam. LilyPond slopes it down by about half a space because it looks only at the outer interval. c285's `gould-concave-damping` treats the start-and-end-on-the-same-note and concave cases from PDF 36 but not this one, so in the basses' run of repeated eighths from 265 this is the only group that tilts.

Evidence: Gould PDF 37, first example under the heading (the beam stays level over the repeated notes while the odd note hangs below it), and the second example (the beam slopes when the odd note is closest to the beam). At 300 dpi, page 16 of v555 shows the slope; the scratch build shows it horizontal and still on a line.

Fix (score.ly, before `gould-concave-damping`; applied in /tmp/critic-555/work):

```
% c555 (Gould PDF 37 "two pitches only in a group of three or more notes"): one different note at the start or end of the group,
% furthest from the beam, and every other note the same -> horizontal. ...
#(define (gould-two-pitch-flat close pits)
  (let ((a (car close)) (z (last close)) (pa (car pits)) (pz (last pits)))
    (and (not (= a z))
         (or (and (< a z) (every (lambda (p) (equal? p pz)) (cdr pits)))
             (and (< z a) (every (lambda (p) (equal? p pa)) (drop-right pits 1)))))))
```

In `gould-concave-damping`, add a `pits` binding (the pitch of the note nearest the beam in each stem, PDF 38) and `(gould-two-pitch-flat close pits)` as a third alternative in the `or` that returns the high damping. It compares pitches, not staff positions, so the chromatic D–D♭–C groups stay sloped (see finding 2). The groups with equal numbers of each pitch (171–186, 277) keep their slope, as PDF 37 allows and c285 decided. Manual `Beam.positions` overrides are unaffected. Result: one group changes (Cb 277); notes, MIDI, analysis and the 16-page layout are unchanged. parts-book.ly still lacks all four beam callbacks, as before.

### 2. 199 and 247: D–D♭–C eighth groups (tested, not changed)

Bars: 199.4 Ob 1, Cl 1 (Fl 1 and Vln I have c195's manual ¼ slope); 247.4 Bn 1, Tbn 2, Vc.

When I first wrote the rule on staff positions, these five groups also became horizontal, because D and D♭ share a staff position. I rejected that version. PDF 37's rule is about groups with only two pitches, and D–D♭–C has three: it is a descending chromatic line, and a level beam would hide that. It would also put these groups out of line with the flute and first violins at 199, which have a deliberate ¼ descent (PDF 35). The applied version compares pitches and leaves all five as they are.
