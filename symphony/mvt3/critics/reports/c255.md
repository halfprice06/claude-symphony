## Findings

### 1. Four string parts turn the page inside the music (applied, parts only)

Bars and parts: viola 191|192 (the A♭-major F2, violas at the tune's lower octave, mp espress.); Violin II 213|214 (theme B episode, f); cello 227|228 (chorale bass, the step to F); double bass 86|87 (closing group, f) and 249|250 (hammered eighths, ff).

Problem: MOLA PDF 7 asks for every turn to fall in a rest or an unexposed passage, "considering the tempo and the playing technique". These five turns cut the inside player out of a melody or a bass line. Violin I and the cellos' first turn were moved by c165, but the other string parts kept the free breaker. Violin II's page 4 was also compressed by 0.3 staff-spaces (the only warning in the v255 parts build).

Evidence: per-player MIDI silence at each turn of the v255 parts: viola 0.00 bars at 192, Violin II 0.00 at 214, cello 0.00 at 228, double bass 0.00 at 87 and 250.

Fix: all string parts now turn where Violin I turns: in the half-bar rest at the end of 66 (pizz. to arco at E) and after 186 (the end of the pizz. accompaniment, before M). Violin II keeps its first turn at 61|62 (pizz. pp, unexposed), because 1-66 does not fit on its page 1. In parts-book.ly:

```
Viola, Violoncello, Double bass:  ... \vla } { s1*66 \pageBreak s1*120 \pageBreak } >>   (vc: replaces { s1*66 \pageBreak })
Violin II:                        ... \vlnTwo } { s1*61 \pageBreak s1*125 \pageBreak } >>
```

Result: viola 5 pages (as before), Violin II, cello and double bass 5 pages (were 4). Pages 4 and 5 face each other, so the number of turns stays at two. All turns now have 0.5-0.75 bars of rest (66, 186) or 16 bars (Violin II at 171-186). The Violin II compression warning is gone.

### 2. Entries after long rests without a cue: bass clarinet 101 and 27, tuba 27 (applied, parts only)

Bars: bass clarinet 101 (p, a sustained note on beat 2, after 66 bars of rest, 35-100, under the string-free wind answer); tuba 27 (ff, F1's bass statement, a part added in c251) and bass clarinet 27 (ff, the same statement), both after 20 bars of rest (7-26).

Problem: MOLA PDF 5: "logical cues are expected during long periods of rest... cues must be audible and obvious"; Example 4 (PDF 10) shows the cue in the bars just before the entry. The trombones got a cue for 35 (c225), but the newer tuba part and the bass clarinet did not.

Fix (part-only, tagged 'part as elsewhere): sections/pOne.ily

```
pOneTuba   = { R1*14 | \tag #'score { R1*2 } \tag #'part { \cueDuring "vc" #UP { R1*2^\markup \tiny "Vc." } } | }
pOneBassCl = { R1*14 | \tag #'score { R1*2 } \tag #'part { \cueDuring "vc" #UP { R1*2^\markup \tiny "Vc." } } | }
```

and sections/dev.ily, devBassCl begins `\tag #'score { R1*2 } \tag #'part { \cueDuring "bsnOne" #UP { R1*2^\markup \tiny "Bn. 1" } } | r4 e,2.~\p | ...` (Bn 1 plays F1's head with the violas at 99-100). The cues print transposed for the B♭ bass clarinet (written A3-B♭3 and G5).

### 3. Tempo texts collide in the Trumpet 1 and harp parts (applied, parts only)

Bars: Trumpet 1 part, "poco rit." (197) runs into "Tempo I" (199) after the rests 187-196 and 197-198; harp part, "allargando" (221) touches "Maestoso" (223).

Problem: MOLA PDF 8 and Example 7 (PDF 12): extracted parts must be proofread because anchored markings collide; Gould PDF 55: no characters may collide. Short multi-bar rests leave too little width for two tempo texts.

Fix, as c235 did for "animando" at 81: global.ily, before each of the two texts,
`\tag #'part \once \override Score.MetronomeMark.outside-staff-horizontal-padding = #1`. The text keeps a space clear on each side and takes its own tier; the score is unchanged (pixel-identical).

### 4. Percussion part: no notation key and no player count (applied, part only)

Problem: one line carries two players and two kinds of notehead (⊗ above, normal below), and the written length is the length of the sound (223 and 263 one bar, 278 tied into 279 and damped on beat 2). MOLA PDF 5 recommends a notation key at the head of a percussion part, and PDF 6 asks for the instruments and the number of players. The score's staff name says "(2 players)"; the part did not.

Fix (parts-book.ly, perc book header): `instrument = "Cymbals, Bass drum (2 players)"` and

```
piece = \markup \normal-text \small \column {
  \line { "Notation key:" \musicglyph "noteheads.s2xcircle" "above the line = crash cymbals (pair);" \musicglyph "noteheads.s2" "below the line = bass drum." }
  \line { "Each stroke rings for its written length and is damped at its end." } }
```

(A `\markup` placed before the `\score` caused a LilyPond programming error with the page-turn breaker, so the key goes in the header.) Still one page.
