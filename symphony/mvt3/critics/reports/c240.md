## Findings

### 1. The first stop chord (138) lacks movement I's trumpet B4 — applied

Bars: 138 (retransition, J).
Problem: Movement I scores both of its stop chords with the trumpets on B4 and F4 (I 26: `b'2.->\ff` / `f'2.->\ff`; I 138: `b'2.->\f` / `f'2.->\f`), and its last trumpet pitch is B4 at I 170. The finale resolves that trumpet B4 to C5 at 222→223, but its first stop chord at 138 has no trumpets at all: strings held sf >, Ob 1 B5 sf >, stopped Hn 3·4 sf >, clarinets and bassoons sub. p. So only the second stop chord tells the listener that the trumpets' B is the note being withheld. As a sforzando, 138 also has only long notes: Rimsky's method (strings sf over winds going to p, PDF 129) is there, but there is no short attack. Adler lists "a short sforzando trumpet note combined with long notes in the strings" as a way to make a sforzando when an accent is not enough (adler2 PDF 189–190, Ex. XV-35, second chord: Tr. I+II, one sf eighth, over Vn I+II whole notes sf > pp). This is exactly the shape of 138 except for the missing trumpets. Adler ch. 1 (adler1 PDF 22) asks that every timbre be a decision of the composition; here the trumpets carry the symphony's B→C thread and are absent at the first of its two finale statements.
Fix (applied in /tmp/critic-240/work/sections/retr.ily): Tpt 1 B4 and Tpt 2 F4, one eighth, sf, at 138 (movement I's pitches for both stop chords), then rests:
```
retrTptOne = { R1 | \tag #'score { R1*2 } \tag #'part { \transposedCueDuring "vlnOne" #UP c { R1*2^\markup \tiny "Vln. I" } } | b'8\sf r8 r4 r2 | R1*6 | ...
retrTptTwo = { R1 | \tag #'score { R1*2 } \tag #'part { \transposedCueDuring "vlnOne" #UP c { R1*2^\markup \tiny "Vln. I" } } | f'8\sf r8 r4 r2 | R1*6 | ...
```
The part-only Vln I cue at 136–137 is there because the trumpets have rested since 113 (MOLA PDF 5, as the existing cue at 145–146). The trumpets' B4 is cut off unresolved; their next B4 (Tpt 2, 147) goes to D, so Tpt 1 B4→C5 is still heard only at 222→223. No other part, pitch, dynamic or bar changes. Rules checked: trumpets tacet 1–50 and first melody at 51 unaffected; no voice reaches C at 138–146; equal simultaneous dynamics on the shared Tpt 1·2 staff (both sf, same rhythm); no ottava. HISTORY c223 listed 135–171 as do-not-touch for form (retransition and recapitulation proportions); this adds no bar, harmony or line, only one attack, so that reason is not affected. The extra trumpet staff on the second system of page 7 pushed 128–143 onto a new page (17 pages), so global.ily gets `\tag #'score \noPageBreak` at the fixed system break before 128; the scratch build is then 16 pages with every page break as in v240.
For finale.md: item 3 and the key-plan stop-chord sentence should add "138: Tpt 1 B4, Tpt 2 F4, sf eighth, movement I 26/138's trumpet pitches, unresolved". This is not a quotation change in themes-finale-quotes.ly (record 37/37 unchanged), but the movement I thread may want to know that the finale now echoes I 26's trumpet layout.
