# Movement III (Scherzo) mockup in REAPER (EastWest Hollywood Orchestra Opus Edition)

Mockup of `symphony/scherzo/v600` (Symphony No. 1, III. Scherzo: Allegro vivace, E minor, Trio in E major; 376 bars of 3/4), built by script through the REAPER file bridge and improved by the actor-critic loop in `loop/`. This folder is local and kept out of git. The method and tools come from `mockup-kit/` (read its README and LEARNINGS first) by way of the two finished ports: Movement I series 2 (`symphony/mvt1/reaper-v621/`, same instrumentation) and Movement II series 2 (`symphony/mvt2/reaper-v600/`). Note: `symphony/mvt3/` is the finale, not this movement.

## Files

- `scherzo-v600-mockup.rpp`: the REAPER project (the only .rpp here). It was written at the port from Movement II's project header (render settings with `RENDER_1X 1`, 48 kHz, no master FX, no tempo points, render path set to `cycles/c00/render`) with no tracks; the first build wrote every track, the tempo map and the pre-roll. 31 instrument tracks, one Opus instance each, stems 01-31 in `build/score_config.py` `TRACKS` order; from c06 also four REAPER return tracks (Spaces II), stems 91-94.
- `build/`: `mockup.ly` (Movement II's extraction: one staff per player plus the drum staff, which is silent here; dumps `mockup.midi` and `mockup-events.tsv`), the score sources copied from v600 (`global.ily`, `parts.ily`, `sections/`) and `score-defs.ily` (score.ly's `\sec` helpers and includes without its layout, MIDI-only fades and roll strokes), all run through `convert-ly` to LilyPond 2.26 (the sections carry no `\version`, so `--from=2.24.0`); `score_config.py` (the scherzo's tables), `parts.json`, `mix.json`, `probe.json`, `ks_maps_extra.json` (Movement I's: DIV A/B, 1TP, 2TP maps), and the per-note tables (`roles`, `note_trims`, `pitch_trims`, `entry_leads`, `early_fills`, `leg_leads`, `loop_fills`, `loop_profiles`, `rebow_fills`, `rebow_moves`, `accent_fits`, `accent_bodies`, `cresc_fronts`, `auto_fills`; all empty at c00 except `rebow_moves.json`'s header).
- `tools/`: the pipeline (score_to_parts, space_rebows, build_reaper, reaper_ctl with owner "scherzo", render_cycle, measure, probe_attacks, pcx, deliver_master, motion, auto_fills, fit_rebows, fit_loops, fit_accents, fit_accent_bodies, stem_fix, rendermap). `mockup-kit/README.md`, Movement I's README ("Tools added in later cycles") and Movement II's README ("Tool changes after the port") describe each.
- `loop/`: `BRIEF.md` (read by every agent), `LENSES.md` (the critics' lenses and the C-lens rotation), `critic_prompt.md`, `actor_prompt.md`, `HISTORY.md`, `LEARNINGS.md`, `MANUAL-READING.md`, `MANUAL-GAPS.md`, `DYNAMICS-RESEARCH.md`, and `PORT_TASK.md` (the port's task).
- `cycles/`: per cycle the critics' `reports/`, `before/`, `render/`, `metrics/`, `CHANGES.md` and the delivered `scherzo-mockup-cNN.mp3`. `cycles/c00/PORT.md` and `cycles/c00/port/` record the port.
- `jobs/`: the Lua jobs and generated Opus states (`NN_<patch>.b64`), and `audio_init.lua` (reopens REAPER's audio device just before a render: `python3 ~/.rpr-bridge/rpr.py run jobs/audio_init.lua`).

## Rebuild from scratch

```
cd build && lilypond -o mockup mockup.ly
~/.venvs/claude-composes-reaper/bin/python ../tools/score_to_parts.py . ~/.rpr-bridge/libs/ew_ho/ks_maps.json parts.json
~/.venvs/claude-composes-reaper/bin/python ../tools/space_rebows.py parts.json --write   # when re-bows changed
~/.venvs/claude-composes-reaper/bin/python ../tools/score_to_parts.py . ~/.rpr-bridge/libs/ew_ho/ks_maps.json parts.json
cd ..
# REAPER is shared by the Movement I, Movement II and finale threads: take the lock first, keep job files in this folder
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py lock "scherzo cNN actor"
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py start && ~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py open
~/.venvs/claude-composes-reaper/bin/python tools/build_reaper.py build/parts.json jobs
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py restart
python3 ~/.rpr-bridge/rpr.py run jobs/audio_init.lua     # reopen the audio device (48000 Hz, 512, no input)
~/.venvs/claude-composes-reaper/bin/python tools/render_cycle.py N
~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py quit && ~/.venvs/claude-composes-reaper/bin/python tools/reaper_ctl.py unlock
```

`score_to_parts.py` must print no WARNING (each one is a printed dynamic the CC11 curve misses, or a stale per-note key).
