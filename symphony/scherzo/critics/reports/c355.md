## Findings

### 1. Vln II 193 needs "unis."; the violas' "unis." at 193 is stale (applied)

**Problem.** c344 moved the trio's off-beat dyads at 169–184 from the violas to Vln II, marked "div." at 169. Vln II rests 185–192 and comes back at 193 on single notes (`fis'2(\p\< gis'4`) with no instruction, so the players are still divided according to their parts. The violas, meanwhile, still carry c085's "unis." at 193. That mark was written for the violas' own divided thirds at 169–184, which they no longer play. Their last double stops are the non div. ones at 105–120, so for them the word now refers to a division that does not exist. The instruction is on the wrong staff.

**Evidence.** Adler PDF 30: "When divisi is no longer in order and the part returns to single notes, the word unisoni (or more commonly the abbreviated, unis.), should appear on the part", and without div. "the player would be correct in performing the chord as a double-stop". The rule works in both directions, so a part has to be told when division begins and when it ends. The score already follows it everywhere else (Vla 225, 352, 357; Vc 245). The scanner found no other single notes after div. in any part, and found that this is the only "unis." without a preceding div.

**Fix (applied, tB.ily).**
```
tBVlnTwo = { R2. | … | R2. | fis'2(\p\<^\markup \italic "unis." gis'4 | a'2 cis''4) | …
tBVla    = { R2. | … | R2. | a4(\p\< b8 a gis a) | a2. | …
```
c085's header comment is annotated, and a c355 comment states the reason. The MIDI is unchanged. The parts build from the same variables. In my parts build the Vln II part now prints 1 "unis." (it had none), and the viola part prints 4 (it had 5).

### Points tested and kept (no change)

- **Vln I/II 280, V on the slurred quaver upbeat.** After four bars of rest an upbeat is naturally up-bow (PDF 38), so the sign only confirms the habit. c318 added it on purpose, following Dvořák 9/iii's up-bow signs on soft entries, and it fixes the bowing plan 277–285. A redundant sign does no harm here. Keep.
- **Hairpins on pizz. at 37–40, 98–99, 249–251, 271–272.** Each one spans two or more plucks, so the crescendo is made by plucking each note louder. This is c265's distinction, unlike the single pluck at 207 that it fixed. Keep.
- **Vc 106–107 slur at ff in the tutti (b2( e'4~ | e'2 b4)).** Three notes in 1.4 s, within Mendelssohn's six notes at forte (PDF 39). Keep.
- **Harp harmonics 375.** The notation is correct as described above. Keep.
- **Layout.** Pages 10–13 end with white space below the last system, but the page breaks set by the rehearsal letters and the trio's system start (c005) give clean turns. The page count stays at 13. No change.
