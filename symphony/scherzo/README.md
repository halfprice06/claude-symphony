# Scherzo (movement III of four) workspace

Owned by the thread "Scherzo actor critic loops". Procedure: ../LOOP-METHOD.md. Set up as a copy of the finale's workspace (mvt3/).
- vNN/: one folder per version (v01 = first draft; cycle N reviews vNN and produces v(N+1); cycle 200 ends at v201).
- movement-scherzo-plan.md: form and material of v01, and the cyclic rules.
- tools/: copy of mvt3/tools (sections.txt third column = quarter beats per bar: 3).
- critics/: BRIEF.md, LENSES.md, MASTERS.txt (master scherzo for each lens-9 cycle), READING.md (generated by kit/syllabus.py), HISTORY.md, reports/cNNN.md.
- kit/: critic_prompt.txt, genprompt.sh N "focus", promote.sh NEW PREV SRC (builds in /tmp/sch and copies back), syllabus.py, v01-generators/ (the scripts that wrote v01; countbars.py checks section lengths of any version).
- Listening renders: symphony/render/r07 (`python3 symphony/render/r07/render.py --score <scherzo/vNN> --out <vNN>/score-r07.mp3 --work /tmp/render-x`), one render at a time across threads.
